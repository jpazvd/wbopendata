## SSC Submission Rules (from official guidelines)

| Rule | Detail |
|------|--------|
| **Zip format** | `.zip` or `.gzip`, emailed to `baum@bc.edu` |
| **`.pkg` file** | **Do NOT include** — SSC auto-generates it from the RePec template |
| **`stata.toc`** | **Do NOT include** — SSC manages this |
| **File structure** | Subdirectories supported — SSC installs each file into matching subdir under `ado/plus/` |
| **Filenames** | Must be globally unique across all of SSC |
| **Command names** | Strictly lower case; avoid reserved graphics words |
| **`version` statement** | Every `.ado` must have `version n.n` |
| **Help files** | `.sthlp` required for version ≥ 10.0 |
| **`varabbrev`** | All programs must work with `set varabbrev off` |

## What to Include

### Required
- All `.ado` files (main commands and internal helpers)
- All `.sthlp` help files

### Recommended
- `.dta` data files (`world-c.dta`, `world-d.dta`)
- `.yaml` metadata files (`_wbopendata_*.yaml`)
- `.txt` data files (`country.txt`, `indicators.txt`)
- `.dlg` dialog file (`wbopendata.dlg`)

### Excluded from SSC

| File/Type | Reason |
|-----------|--------|
| `stata.toc` | Auto-generated by SSC |
| `wbopendata.pkg` | Auto-generated by SSC |
| `__COMPONENT_VERSIONS.yaml` | Internal developer manifest |
| `src/py/*.py` | Python scripts land in `ado/plus/w/` when SSC-installed, but `forcepython` looks in `ado/plus/py/` — wrong directory; pathway unavailable to SSC users |
| `update_metadata.do` | Hardcoded developer paths |

> **Note on `forcepython`:** The Python-assisted metadata sync (`wbopendata, sync forcepython`) requires Python files in `c(sysdir_plus)py/`. SSC's flat install puts all files in `ado/plus/w/`, so `forcepython` is unavailable after SSC install. Users who need it should install from GitHub (`net install`) or manually copy `src/py/` to their `ado/plus/py/` directory.

## Build the Zip

```powershell
cd C:\GitHub\myados\wbopendata-dev
.\ssc\build_ssc_package.ps1
```

Output: `ssc\wbopendata-v<version>.zip`

The build script:
1. Copies all distributable files from `src/w/`, `src/_/`, `src/y/`, `src/c/`, `src/i/` into a flat temp directory
2. Excludes `stata.toc`, `wbopendata.pkg`, `__COMPONENT_VERSIONS.yaml`, and all `py/` files
3. Zips everything flat
4. Reports file count by type

**Expected counts for v18.4.1:** ~77 files (54 ADO + 12 STHLP + 4 YAML + 2 DTA + 5 other)

## Pre-Submission Checklist

- [ ] Version number updated in `src/w/wbopendata.ado` (`version` statement and changelog)
- [ ] Version number updated in `CITATION.cff`
- [ ] All `.ado` files have a `version n.n` statement
- [ ] All commands work with `set varabbrev off`
- [ ] QA suite passes: `do qa/run_tests_dev.do`
- [ ] Zip built with `build_ssc_package.ps1`
- [ ] Zip file is non-zero size
- [ ] No `.pkg` or `stata.toc` in zip (verify below)
- [ ] No Python files in zip

```stata
* Verify zip contents in Stata (run from wbopendata-dev root)
shell python -c "import zipfile; z=zipfile.ZipFile('ssc/wbopendata-v18.4.1.zip'); [print(n) for n in sorted(z.namelist())]"
```
